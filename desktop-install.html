Install GIS Co-Scientist Desktop

Windows macOS Apple Silicon macOS Intel

Windows

Download Windows installer (.exe)

  1. Open the downloaded setup file and follow the installation prompts.
  2. If setup reports that Microsoft Edge WebView2 is missing, install the WebView2 Runtime and run setup again.
  3. Open GIS Co-Scientist from the Start menu.
  4. In Settings, add your own OpenAI API key. If you only want to test or try out the system, you can use a GIBD key as a backup.

macOS Apple Silicon

Use this installer if Apple menu > About This Mac shows an Apple chip.

Download Apple Silicon installer (.dmg)

  1. Open the downloaded disk image and drag GIS Co-Scientist into Applications.
  2. Open GIS Co-Scientist from Applications.
  3. If macOS blocks the first launch because it cannot verify the developer, follow Apple's guidance for opening the app.
  4. In Settings, add your own OpenAI API key. If you only want to test or try out the system, you can use a GIBD key as a backup.

macOS Intel

Use this installer if Apple menu > About This Mac shows an Intel processor.

Download Intel installer (.dmg)

  1. Open the downloaded disk image and drag GIS Co-Scientist into Applications.
  2. Open GIS Co-Scientist from Applications.
  3. If macOS blocks the first launch because it cannot verify the developer, follow Apple's guidance for opening the app.
  4. In Settings, add your own OpenAI API key. If you only want to test or try out the system, you can use a GIBD key as a backup.

For help using GIS Co-Scientist after installation, see the User Manual.

If you cannot install the desktop app, use the WebUI in your browser.
